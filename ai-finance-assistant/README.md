# AI 金融小助手（简易大语言模型教学项目）

一个**零第三方依赖、纯 Python 标准库**实现的迷你对话模型，方向是 **AI + 金融**。
它用最简单的代码，演示大语言模型最核心的思想——**"根据前文，预测下一个字"**。

> 本项目仅供学习大语言模型原理使用，不构成任何投资建议。

## 一、三步跑起来

1. 确认电脑装了 Python（3.8 及以上即可，本项目用的是 3.14）。
2. 在本项目文件夹里打开命令行，运行：

   ```bash
   py main.py
   ```

   （如果你的电脑 `py` 命令不可用，也可以试 `python main.py`。）

3. 直接输入问题开始聊天，例如：

   ```
   你：什么是复利
   你：新手如何开始理财
   你：什么是市盈率
   ```

## 二、它能做什么

| 输入 | 效果 |
| ---- | ---- |
| 一个金融问题 | 先查**知识库**，给出准确的现成答案 |
| 知识库没有的问题 | 用**语言模型**现场"编"一段话（演示生成原理） |
| `:gen 股票` | 强制让语言模型以"股票"开头生成一句话 |
| `:temp 1.5` | 调整生成"温度"（0.1~2.0，越低越保守，越高越大胆） |
| `:help` | 查看所有指令 |
| `:quit` | 退出 |

## 三、项目文件说明

```
ai-finance-assistant/
├── main.py              程序入口：交互式聊天界面
├── chatbot.py           机器人逻辑：知识库检索 + 语言模型生成
├── ngram_model.py       语言模型：统计"前文后面跟什么字"的概率
├── tokenizer.py         分词器：把句子切成一个个 token
├── data/
│   ├── finance_faq.json  金融知识库（问答对）
│   └── finance_corpus.txt 金融语料（训练语言模型的"教材"）
├── make_pdfs.py         用来重新生成两份 PDF 手册的脚本
├── 使用手册.pdf          【使用手册】怎么用这个项目
├── 原理手册.pdf          【原理手册】通俗讲解大语言模型原理
└── README.md            本文件
```

## 四、推荐学习顺序

1. 先跑起来，玩一玩（问问题、`:gen`、`:temp`）。
2. 读 **《原理手册.pdf》**，理解"预测下一个字"到底是什么意思。
3. 对照 **《使用手册.pdf》** 的"文件结构"章节，读源码。
4. 动手改一改：往 `finance_corpus.txt` 里加几行金融句子，或往 `finance_faq.json` 里加问答，看效果变化。

## 五、常见问题

- **乱码**：直接运行 `py main.py` 一般不会乱码；如果是重定向到文件，本程序已自动按 UTF-8 处理。
- **`py` 不是内部或外部命令**：说明没装 Python 或没装对，去 python.org 下载安装并勾选"Add to PATH"。
- **想改"聪明程度"**：语言模型的"智商"来自数据。多往 `finance_corpus.txt` 加金融句子，它就能编得更像样。
